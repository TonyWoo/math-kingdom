# 任务：为「数学王国」一次性生成全部美术资源，并打包交付

## 0. 背景

「数学王国」是一个给 6–12 岁小学生用的数学学习网页游戏，用 three.js 渲染 3D 场景，主要在平板和手机的浏览器里运行。
王国是海上的一座圆形岛屿：王城在中央，外面一圈圈台地代表一到六年级，越往外越高；每个知识点是一块地，孩子答对题就能在地上盖房子，一共 284 块地。
你要生成游戏需要的全部 3D 模型和 2D 图片，按下面的规格做好，最后打包成一个 zip 交付。

## 1. 参考图和统一画风

**附件说明：**

- `overview.png`、`all-built.png`、`close-up.png`：游戏现在的 3D 原型截图（王国全景、全部建满、近景）。画面里的建筑、王城、树木都是用代码临时拼出来的占位模型。
  请保持同样的低多边形、平面着色风格和整体比例，把这些占位模型做得更精致、更有个性。截图只用来参考风格、比例和配色，不要照抄占位模型的造型。
- `sheet1.png`（如果附了）：同一个项目里另一款 2D 游戏的插画素材。它**只**用来参考王城和红方士兵（骑士、狼、投石车）长什么样、用什么颜色，让两款游戏看起来属于同一个世界。
  不要模仿它的描边、渐变和手绘质感。

**画风要求：**

- 明亮的低多边形（low-poly）卡通风格，平面着色（flat shading），面数少、轮廓清楚、颜色饱和、看起来友好。
- 主色板：草绿 #8FD65F、沙土 #E8C983、木头 #A8733F / #7A5233、石头 #B9B3A6、墙面米白 #F3EAD8、屋顶红 #D9534A、屋顶蓝 #4A7FD8、金色 #F2C230、水蓝 #5CC4F0、哥布林绿 #6CC24A。
- 不要写实材质，不要法线贴图，不要金属度和粗糙度贴图，不要透明的玻璃。
- **任何图片里都不要出现文字**（包括中文、英文和数字），界面文字由程序绘制。唯一的例外见 2.4 节的 logo。
- 不要模仿任何现有游戏、品牌或知名角色。

## 2. 资源清单

### 2.1 3D 模型（glTF 2.0 二进制 .glb）

**通用技术规格（每个模型都必须满足）：**

- 坐标：Y 轴朝上，单位 1 = 场景里 1 个单位。
- 原点在模型底面中心，底面贴着 y = 0。
- 正面朝向 +Z（镜头默认从 +Z 方向斜着往下看）。
- 材质：所有模型共用**一个**材质，命名为 `palette`，贴图是一张共享的调色板贴图 `textures/palette.png`（256×256，由一格格纯色色块组成）。模型的 UV 指向对应的色块。不要用顶点色，不要给单个模型配独立贴图。
- 不要灯光、不要相机、不要空节点；网格不要带缩放和旋转（把变换应用到顶点上）。
- 会动的零件做成单独的命名节点，节点原点放在旋转轴上（具体见各模型的说明）。
- 三角形预算写在每个模型后面，不能超过。

## 3. 交付格式

打包成 `math-kingdom-art-v1.zip`，目录结构：

```
math-kingdom-art-v1/
  models/            全部 .glb（按 2.1 节的文件名）
  textures/          palette.png、palette.json 和地形贴图
  sprites/
  ui/128/  ui/256/   图标
  app/
  promo/             可选
  preview/
    models_sheet.png 所有模型的缩略图拼成一张总表（统一的 3/4 俯视角度，白底，每格下方标出文件名）
    ui_sheet.png     所有图标的总表
  manifest.json
  CHECKLIST.md
  LICENSE.txt
```

`manifest.json` 里每个文件一条记录，例如：

```json
{
  "file": "models/mill_2.glb",
  "kind": "model",
  "triangles": 1084,
  "bbox": { "min": [-0.28, 0, -0.28], "max": [0.28, 0.78, 0.3] },
  "animatedNodes": [{ "name": "blades", "axis": "z" }],
  "material": "palette"
}
```

图片的记录写 `kind`（`texture` / `sprite` / `ui` / `app` / `promo`）和 `width`、`height`。

`LICENSE.txt` 写明：这些资源是本次生成的原创内容，可以在「数学王国」项目里以 CC0 或同等宽松的条件自由使用、修改和再发布。

## 4. 交付前自检

逐项确认，并把结果写进 `CHECKLIST.md`：

1. 每个 .glb 都能通过 glTF Validator（没有 error），并且能在 three.js 的 GLTFLoader 里正常加载。
2. 每个模型的三角形数和包围盒都在规定范围内，原点在底面中心，正面朝 +Z。
3. 所有模型只用 `palette` 一个材质，引用同一张 `palette.png`。
4. 动画节点的名称正确、原点在旋转轴上；绕规定的轴旋转时，零件不会脱离模型。
5. 同一种建筑的 1 星、2 星、3 星放在一起看，能明显看出是在一步步升级。
6. 除了 `logo_title.png`，所有图片里都没有文字（气泡里的 ? 和 ! 符号除外）。
7. 平铺贴图四边能无缝衔接。
8. zip 解压后总大小不超过 15 MB，其中模型一共不超过 4 MB。

有任何一项做不到，就在 `CHECKLIST.md` 里写明是哪一项、原因是什么，不要悄悄省略。
